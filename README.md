# 🏠 Global Airbnb Performance Dashboard

## 📌 Project Overview

This project presents an interactive **Global Airbnb Performance Dashboard** developed in **Microsoft Power BI**.

The dashboard analyzes Airbnb listings, hosts, reviews, cities, property types, market share, ratings, review frequency, and host trust indicators.

The objective is to transform Airbnb data into an interactive business intelligence dashboard that makes it easier to explore market patterns, compare cities, understand review behavior, and analyze host-related indicators.

---

## 📊 Project Highlights

- **279.712K** Listings
- **182.024K** Hosts
- **5.373143M** Reviews
- **10** Cities
- **144** Property Types
- Interactive Power BI dashboard
- City-level market share and rating analysis
- Review frequency and host trust analysis

---

## 🔍 Dashboard Analysis

### 1. Global Performance

The first section provides an overview of Airbnb performance and listing activity over time.

It includes:

- Total Listings
- Total Hosts
- Total Reviews
- Number of Cities
- Property Types
- New Listings
- Listing Trends Across Years

This section provides a high-level view of listing activity across the available timeline.

---

### 2. Market Share by City

The second section compares Airbnb performance across 10 cities.

The analysis includes:

- Listings by City
- Superhost Listings
- Non-Superhost Listings
- Cumulative Market Share
- Accuracy Ratings
- Value Ratings
- Cleanliness Ratings
- Communication Ratings
- Location Ratings

The dashboard highlights **Paris, New York, and Sydney** as major contributors within the analyzed listings and review data.

It also provides a city-level comparison across multiple rating categories.

---

### 3. Review Frequency & Host Trust

The third section focuses on customer review behavior and host-related trust indicators.

It includes:

- Reviews per Reviewer
- Monthly Review Distribution
- City-level Review Activity
- Host Verification
- Profile Picture Availability
- Trust Indicators

The dashboard shows review-frequency patterns and highlights unusually high review activity that may require further investigation or data validation.

---

## 💡 Key Insights
